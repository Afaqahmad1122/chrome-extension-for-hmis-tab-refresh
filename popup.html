Troubleshooting guide
Blank or half-loaded page
Click Fix Health Cloud. If still blank, run Check connection.
Buttons not responding
Click Hard refresh, then Fix Health Cloud.
Login errors
Save work, log out, log in again. If it persists, use Reset session data.
Missing menus or permissions
Log out and in again. If still missing, contact IT: permissions are set by the server.
Slow loading
Run Check connection. A slow result points to the network, not your browser.
