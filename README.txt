HMIS Smart Support - installation

1. Extract the ZIP to a permanent folder (do not delete it afterwards).
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode (top right).
4. Click Load unpacked and select the extracted hmis-smart-support folder.
5. Click the puzzle icon in the toolbar and pin HMIS Smart Support.

Use: open the HMIS tab, click the extension, press Fix HMIS.

Update: extract the new ZIP over the same folder, then click Reload on the extension card in chrome://extensions.
Uninstall: click Remove on the extension card.

IT setup: edit config.js to set the helpdesk phone and email before distributing.
